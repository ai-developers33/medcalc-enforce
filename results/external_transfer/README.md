# MedCalc-Pro Simple eligibility for independent transfer evaluation

The pinned MedCalc-Pro Simple split includes 1,048 cases. We examined all 200 cases whose calculator IDs appear in the frozen registry. Each ID has 20 rows and the expected tool metadata. The frozen intent selector identifies the listed calculator from the doctor query in all 200. These tasks name the target calculator. Of the 200 queries, 180 request the first admission before treatment. The 20 Bazett queries request the answer in seconds, whereas the current executor returns milliseconds.

Every supported case shares a source key with the Verified test corpus. Of those, 197 also have identical normalized note text. Restricting overlap to the study’s actual exclusion universe, 126 cases share a source or normalized note with one of the two locked official cohorts and the other 74 share a source or normalized note with the pinned training or one-shot splits. This leaves **zero eligible cases**. A separate benchmark distribution here supplies no independent transfer sample for the implemented calculators. External accuracy remains unmeasured.

The script uses the existing source-key rules, pinned dataset digests and publicly declared calculator metadata. Source-key identity is based on article identifiers when available, and on the study’s scoped note identifiers elsewhere. It checks numerical output units and intent metadata without running the calculator, ingesting the case-level reference results, or tuning the frozen engine. The formula and output-unit mapping is in `summary.json`. A generic BSA, anion-gap, or osmolality question can leave a formula convention implicit. A future external dataset with eligible cases would also require confirmation of its precise reference conventions.

Reproduce with `python3 audit_medcalc_pro_transfer.py --raw data/raw` after fetching the pinned source data. The output contains aggregate counts and nonidentifying hashes only. No external source notes, queries, measurements, or reference answers are redistributed.
